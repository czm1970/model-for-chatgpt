# JavaScript

- 从 package.json、锁文件、引擎配置和构建工具确认浏览器或 Node.js 环境、包管理器、ESM 或 CommonJS。沿用项目模块体系；已有 TypeScript 时保持其类型边界。
- 优先运行已有 scripts，不因个人偏好切换 npm、pnpm、yarn 或框架。运行安装或构建前注意生命周期脚本的实际行为。
- 异步逻辑处理拒绝、超时、取消和重复请求竞态；事件监听、计时器与订阅在对应生命周期释放。
- 浏览器端不可包含服务端密钥。验证来自表单、URL、存储和 API 的数据，不依赖隐式类型转换或真值判断区分合法的 0、空字符串与缺失值。
- 使用现有测试工具验证状态变化与错误路径。页面任务结合 HTML 参考检查可访问性和真实浏览器交互；服务端任务检查状态码及错误响应契约。
