# Python

- 从 pyproject.toml、锁文件、requirements 和 CI 确认 Python 版本、包管理器及 src 布局；使用项目虚拟环境，不全局安装依赖。
- 运行测试时使用对应解释器的模块入口，例如 python -m pytest，并以项目已有配置为准。不要引入与现有包管理工具竞争的新锁文件。
- 区分同步和异步库；async 函数中避免阻塞网络或长计算。处理外部资源时保留超时、关闭和异常上下文。
- 使用明确编码处理文本；路径用 pathlib 或现有抽象。避免模块名遮蔽标准库、依赖当前工作目录以及导入时产生网络或文件副作用。
- 类型检查、ruff、mypy 等仅在已有配置或任务需要时使用；测试应验证行为与关键数据边界，而非逐句复制实现。
