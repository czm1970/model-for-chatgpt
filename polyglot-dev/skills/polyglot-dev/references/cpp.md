# C++

- 从 CMakePresets.json、CMakeLists.txt 或现有构建文件确定编译器、标准、目标和依赖。保留平台与 ABI 约束，不默认升级语言标准。
- 使用现有 preset；没有 preset 时考虑独立构建目录，例如 cmake -S . -B build。多配置生成器的构建与 ctest 要使用一致的配置。
- 用 RAII 表达资源生命周期，明确指针、引用、string_view 和 span 的所有权及有效期；检查容器扩容后的迭代器失效。
- 检查有符号与无符号转换、越界、整数溢出和未定义行为。不要为了消除诊断而简单强制转换或关闭警告。
- 修复内存或并发问题时，在支持的平台和现有构建方式下选择 sanitizer 或调试器；说明工具不可用的情况，不强制加入平台特定编译参数。
